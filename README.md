# Construct3-New-Project

## Releases

r495.2 stable

An empty [Construct 3](https://editor.construct.net/) ([affiliate link](https://www.construct.net/a/260259?t=construct3)) project, saved as a folder project.

## Use

A starting point for a project created outside the editor: copy the folder, rename it, and open it in Construct 3 or hand it to an agent.

[Construct3-RAG](https://github.com/XHXIAIEIN/Construct3-RAG) copies it to start a project:

```bash
python Construct3-RAG/scripts/bootstrap.py --project MyGame
```
